Project Overview

About This Project

This project is a fully functional AI-assisted dashboard system designed for a digital agency. The platform includes two separate dashboards — an Employee Dashboard and an Admin Dashboard — built to create a clean, efficient, and scalable internal management system.

Employee Dashboard

A focused interface giving employees quick access to attendance, tasks, timesheets, leave requests, payslips, and profile management tools.

Admin Dashboard

A comprehensive control panel for management teams covering employee management, client tracking, project monitoring, and operational reporting.

AI-Assisted Workflow

The project leverages AI-assisted generation with extensive human-led ideation, prompt engineering, iteration cycles, and usability-driven refinements.

Scalable Architecture

Designed with a modular structure to allow future feature expansion, additional integrations, and seamless scaling as the agency grows.

This project demonstrates how AI-assisted workflows can be strategically used in modern UI/UX and product design processes — transforming generated outputs into purposeful, agency-oriented management platforms through continuous direction and refinement.

Methodology

Design Approach

The project was created using a hybrid workflow — an AI + Human Collaboration Process. The base dashboard layouts and components were generated using AI-assisted tools, while overall product direction, feature structure, design refinement, and user experience decisions were guided manually.

01

Multiple Iteration Cycles — Rather than accepting initial AI-generated outputs, every screen went through structured iteration rounds to align with actual agency workflows and user needs.

02

Continuous Prompt Refinement — Prompts were strategically refined at each stage to push AI outputs closer to the intended design vision, ensuring purposeful and accurate generation.

03

Workflow Optimization — Every design decision was evaluated against real operational workflows, ensuring the dashboard reduces friction rather than adding complexity.

04

Brand-Based Customization — Visual language, color systems, typography choices, and component styles were refined to reflect a cohesive and professional agency brand identity.

05

UX-Driven Restructuring — Information architecture was continuously restructured based on user behavior patterns, task frequency, and accessibility of critical data points.

06

Practical Feature Organization — Features were grouped, prioritized, and organized based on actual agency operational needs rather than generic dashboard templates.

This methodology helped transform generic AI-generated screens into a more purposeful and agency-oriented management platform with clear functional intent.

Design Process

How We Got There

The design followed a structured five-phase process that combined strategic planning with AI-assisted generation and extensive human refinement to deliver a purposeful, well-crafted product.

Phase 01 — Research & Planning

Understanding the agency's operational requirements, team structure, and management challenges before any design work began.

  • Agency workflow analysis
  • Feature requirement mapping
  • Information architecture planning
  • Workflow and navigation structure

Phase 02 — AI-Assisted Generation

Using AI tools with strategic prompts to generate initial dashboard layouts, component structures, and screen variations as a fast starting point for the design system.

  • Prompt engineering for accurate outputs
  • Initial layout generation
  • Component library starting point
  • Multiple variation exploration

Phase 03 — Design Refinement

Extensively reviewing and refining the AI-generated outputs to align with the agency's brand, operational needs, and user experience standards through manual design work.

  • Visual hierarchy refinement
  • Typography and color system alignment
  • Component consistency review
  • Brand identity integration

Phase 04 — UX Optimization

Restructuring information architecture based on user workflows, simplifying navigation patterns, and optimizing every screen for daily usability and operational efficiency.

  • Navigation structure optimization
  • Task flow simplification
  • Content hierarchy restructuring
  • Accessibility and clarity improvements

Phase 05 — Iteration & Validation

Running multiple iteration cycles across both dashboards to validate design decisions, test layout effectiveness, and ensure consistency across all screens and user flows.

  • Cross-screen consistency checks
  • Layout effectiveness validation
  • Feature completeness review
  • Final design polish and cleanup

Challenges

Design Challenges

This project came with a distinct set of challenges that required careful thinking, strategic decision-making, and iterative problem-solving throughout the design process.

Dual Dashboard Coherence

Designing two separate dashboards — Employee and Admin — that feel visually consistent with each other while maintaining distinct navigation patterns, feature sets, and interaction models appropriate to each user role.

AI Output Refinement

Transforming AI-generated screens — which often produce generic, template-like outputs — into purposeful, agency-specific interfaces required sustained creative direction and multiple iteration cycles.

Information Density Balance

Admin dashboards naturally carry high information density. Finding the balance between showing comprehensive data and maintaining a clean, non-overwhelming visual experience was a core UX challenge.

Scalable Structure Design

Designing the system to be scalable for future features and modules — without adding unnecessary complexity to the current interface or disrupting the established navigation and layout patterns.

Role-Based Experience Design

Ensuring that the differences between Employee and Admin experiences feel natural and purposeful rather than artificially restricted, with each role having access to exactly what they need.

Confidentiality Constraints

Designing and documenting a case study while maintaining client confidentiality — presenting the design process, decisions, and outcomes without revealing protected business information or identifying details.

Visual Design

UI Design Decisions

The visual language of the dashboard system was deliberately crafted to feel professional, modern, and agency-grade — avoiding the generic aesthetic often associated with default admin panels.

Color System

  • Primary brand blue for key actions and navigation
  • Clean white backgrounds for readability
  • Subtle grays for secondary content and borders
  • Soft accent tones for status indicators

Typography Hierarchy

  • Clear heading levels for content navigation
  • Distinct body text sizing for readability
  • Label styles for metadata and table content
  • Consistent weight usage across components

Component Design

  • Consistent border radius across all UI elements
  • Subtle shadow system for depth and hierarchy
  • Hover states communicating interactive affordance
  • Clear button hierarchy (primary, secondary, ghost)

Layout Principles

  • Fixed sidebar navigation for persistent wayfinding
  • Content area designed with generous breathing room
  • Card-based information grouping for clarity
  • Consistent grid system across all screen types

Learnings

Key Learnings

This project offered valuable insights into AI-assisted design workflows, the importance of human direction in AI product development, and the complexities of designing dual-role management systems.

01

AI is a starting point, not an endpoint. While AI tools can dramatically accelerate initial generation and exploration, the quality of the final product depends entirely on the quality and persistence of human direction, iteration, and creative refinement applied after generation.

02

Prompt engineering is a design skill. The ability to craft precise, context-rich, and strategically sequenced prompts is as important as traditional design execution when working in AI-assisted workflows. Poor prompting leads to generic outputs regardless of the tool being used.

03

Role-based UX requires deep empathy. Designing for two fundamentally different user types — employees and admins — requires genuine understanding of their daily workflows, priorities, pain points, and mental models, rather than simply restricting or expanding feature access.

04

Information hierarchy is the core challenge in dashboards. The most critical skill in dashboard design is deciding what information appears at what level of prominence — not the visual aesthetics. Getting hierarchy wrong makes even beautiful dashboards frustrating to use.

05

Scalability must be designed in from the beginning. Building layout systems, navigation patterns, and component structures that can accommodate future features without requiring redesign from scratch is a far more efficient approach than retrofitting scalability later.

06

Consistency is more valuable than novelty in utility interfaces. For internal management tools, consistent interaction patterns and predictable navigation structures create more value for users than creative or experimental design choices that break expected conventions.
